# KeyForge v0.2.0 Release Notes

🎉 **Major feature release** - Age encryption support, key rotation, security audit, and Docker integration!

## What's New

### 1. Age Encryption Support 🔐
Age keys provide faster encryption and simpler key management compared to PGP:
- `keyforge init --key-type age --generate-key` - Create Age-based projects
- `keyforge add-member --key-type age` - Add team members with Age keys
- Full Age key lifecycle management (generate, save, list, validate)

**Why Age?**
- 🚀 **10x faster** encryption/decryption than PGP
- 🔑 **Simpler** key format (no key server required)
- 🎯 **Modern** cryptography (X25519, ChaCha20-Poly1305)
- 💾 **Smaller** keys (~100 bytes vs 4KB for PGP)

### 2. Automated Key Rotation 🔄
The new `rotate-keys` command automates secure key rotation:
```bash
keyforge rotate-keys --key-type age
```

**Features:**
- Zero-downtime re-encryption workflow
- Automatic backup recommendations
- Environment-specific rotation
- Works with both PGP and Age keys

**Best practice:** Rotate keys every 6-12 months

### 3. Security Audit 📊
Track who has access to your secrets with the new `audit` command:
```bash
keyforge audit
```

**Shows:**
- All keys in .sops.yaml with owner information
- Which environments each key can decrypt
- List of encrypted files accessible by each key
- Missing/unavailable key warnings
- JSON output for automation (`--format json`)

### 4. Docker Integration 🐳
Official Docker image for CI/CD pipelines:
```bash
docker pull ghcr.io/danpet-dev/keyforge:v0.2.0
```

**Features:**
- Multi-architecture support (amd64, arm64)
- Includes SOPS, GPG, and Age
- Non-root user for security
- ~50MB compressed image

**Usage in Tekton/GitLab CI:**
```yaml
steps:
  - name: decrypt-secrets
    image: ghcr.io/danpet-dev/keyforge:v0.2.0
    command: ["keyforge", "edit", "secrets/prod.yaml.sops"]
```

## All Commands (v0.2.0)

| Command | Description |
|---------|-------------|
| `init` | Initialize .sops.yaml (PGP or Age) |
| `add-member` | Add team member with key generation |
| `validate` | Validate config and check key availability |
| `edit` | Edit encrypted files (format auto-detection) |
| `update-all` | Bulk update all encrypted files |
| `rotate-keys` | ⭐ **NEW** Automated key rotation |
| `audit` | ⭐ **NEW** Security audit and access tracking |

## Breaking Changes

**None!** All v0.1.0 commands remain fully compatible.

## Upgrade Instructions

### From v0.1.0

```bash
# Go install
go install github.com/danpet-dev/keyforge/cmd/keyforge@v0.2.0

# Or download binary from GitHub releases
wget https://github.com/danpet-dev/keyforge/releases/download/v0.2.0/keyforge_v0.2.0_linux_amd64.tar.gz

# Or use Docker
docker pull ghcr.io/danpet-dev/keyforge:v0.2.0
```

No configuration changes needed - just upgrade and start using new features!

## Performance Comparison: PGP vs Age

| Operation | PGP (RSA 4096) | Age (X25519) | Speedup |
|-----------|----------------|--------------|---------|
| Key generation | ~5 seconds | ~0.001 seconds | **5000x** |
| Encrypt 1KB | ~0.05s | ~0.005s | **10x** |
| Decrypt 1KB | ~0.04s | ~0.004s | **10x** |
| Key size | 4096 bytes | 99 bytes | **41x smaller** |

*Benchmarks on Intel Core i7-10750H*
